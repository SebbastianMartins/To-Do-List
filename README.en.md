# 📝 Task List

A simple web app for managing tasks, built with **HTML**, **CSS**, and **vanilla JavaScript**.

## 📸 Preview

![App preview](images/SS.png)

## 🚀 Features

- Add new tasks
- Edit existing tasks
- Delete tasks
- Auto-saving to `localStorage`
- Friendly and responsive UI with green pastel gradient background

## 🛠️ Technologies Used

- HTML5
- CSS3 (with `linear-gradient` background)
- JavaScript (no frameworks)
